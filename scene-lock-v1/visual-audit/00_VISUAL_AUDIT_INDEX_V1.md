## 一、審核原則

每幕必須同時通過以下項目，才可以回到 `SCENE_LOCK_V58.md` 標記 `🔒已鎖定`：

1. **故事一致**：圖片不是裝飾，而是真的在演該幕事件。
2. **九尾一致**：同一位明確成年九尾女性；臉、狐耳、髮型、黑紅和服、九尾、身材比例不可突然換人。
3. **構圖完整**：依劇情檢查頭、臉、眼、唇、脖、胸線、手勢、腿、尾巴與關鍵道具。
4. **桌機可用**：16:9／常見筆電比例下不會因 `cover` 把關鍵人物裁壞。
5. **手機可用**：9:16 以獨立構圖優先，不拿橫圖硬裁；上方狐耳與下方手勢不可被 UI 吃掉。
6. **文字安全區成立**：文字、選項、命牒不可擋人物或證據。
7. **互動點正確**：臉、唇、棋子、紅線、鏡片、狐面等 hotspot 要綁原圖 normalized 座標／SVG，不用螢幕死座標。
8. **不過度重複**：同一張主圖原則只當一次主場景；第五卷伏筆回收例外，但必須有狀態變化。
9. **近身特寫允許**：高潮、誘惑、近身頁可故意放大臉／胸／上半身，但不可裁掉關鍵表情、手勢或擋字。
10. **命牒專圖**：命牒頁圖片生成／選圖時就要預留文字紙面，不是後來用 CSS 把白紙蓋在人身上。

## 二、文字安全區代號

### `S-L`｜左文右人
- 桌機文字：約 X 4–36%。
- 九尾／關鍵物件：約 X 45–95%。

### `S-R`｜右文左人
- 桌機文字：約 X 64–96%。
- 九尾／關鍵物件：約 X 5–58%。

### `S-CLOSE`｜近身特寫
- 大面積側欄退場。
- 上方只留短標題；主要對話／操作放下方。
- 眼、唇、脖、胸線、手勢不可被 UI 蓋。

### `S-EVIDENCE`｜證據／異象
- 先保留證據物件 25–40% 清楚可讀區。
- 文字放在證據相反側。

### `S-OPERATE`｜操作幕
- 主要操作物件置中或偏中下。
- 文字極少，只保留必要操作提示。
- hotspot 跟原圖座標走。

### `S-DESTINY`｜命牒
- 桌機左側命牒約 38–43vw。
- 九尾位於右側 45–55% 以上區域。
- 手機需獨立直式命牒構圖或非破壞性版型。

---

## 三、手機共通安全區

- 0–12%：頂部 UI／瀏海安全區，不能放狐耳尖、眼睛或重要文字。
- 15–58%：人物／主道具黃金區。
- 62–96%：對話與選項主要區。
- 若操作物在下方，UI 必須縮短或移位，不可把玩家要點的東西蓋住。

## 四、狀態

- `🟢`：優先保留。
- `🟡`：圖可留但需焦點／手機／文字位置校正。
- `🟠`：優先從現有素材庫換圖。
- `🔴`：高度敘事場景，現圖若缺關鍵動作就專用新圖。
- `🔧`：程式／互動必修。
- `⬜`：尚未實機鎖定。
- `🔒`：桌機＋手機＋故事＋互動全部核准。
