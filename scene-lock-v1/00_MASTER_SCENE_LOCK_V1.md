## 二、固定角色規格：九尾

所有卷別都必須是同一位明確成年九尾女性：

- 長黑髮、白色狐耳、九條大型淡白蓬鬆尾巴。
- 成熟女性臉型、白皙發光肌膚、黑紅花紋和服、精緻花簪。
- 成熟、性感、危險，但不以裸露取代劇情。
- 頭、狐耳、眼、唇、脖、胸線、手勢與身體比例必須自然。
- 近身、高峰、誘惑頁可讓臉／胸／上半身佔畫面 60–75%，但不可把關鍵五官、狐耳或動作裁壞。
- 一般劇情頁以完整場景與動作為優先，不得把每一幕都做成漂亮肖像。
- 九尾的臉型、狐耳、髮型、服裝、尾巴、頭飾不能跨幕明顯變成不同角色。

## 三、圖片不是裝飾：每一幕固定檢查 10 件事

1. 這幕故事目的。
2. 九尾正在做什麼。
3. 玩家正在看／碰／選什麼。
4. 圖片是否真的包含該動作或證據。
5. 桌機是否滿版安全。
6. 手機是否另有安全構圖，不用橫圖硬裁。
7. 文字是否避開臉、狐耳、脖、胸、手與關鍵道具。
8. hotspot 是否跟圖片一起縮放／裁切。
9. 是否和前後頁視覺過度重複。
10. 是否推進情緒與劇情，而不是只換一句台詞。

## 四、文字安全區標準

### S-L｜左側文字安全區
- 桌機：文字主區約 X=4–36%，上／下依場景調整。
- 人物／關鍵道具應主要落在 X=44–96%。
- 手機：人物主體優先放中上 18–60%；文字／選項主要落下方 62–96%。

### S-R｜右側文字安全區
- 桌機：文字主區約 X=64–96%。
- 人物／異象／道具主要落在 X=4–56%。
- 手機仍以中上人物＋下方 UI 為原則，不照搬桌機左右分欄。

### S-CLOSE｜近身／高潮
- 桌機：不使用大型側欄；標題上方小區＋下方對話／選項。
- 臉、眼、唇、狐耳、手勢是最高優先安全元素。
- 手機：上方 0–12% 避免放狐耳；下方 62–100% 預留 UI，不把唇／手放在最底部。

### S-EVIDENCE｜證據／道具
- 文字放道具相反側。
- 證據本身至少保留畫面約 25–35% 的清楚可辨區域。
- 不可讓 UI 把姓名牌、棋子、紅線、鏡像差異、狐面等關鍵資訊蓋住。

### S-DESTINY｜命牒
- 桌機：左側約 4–42% 為命牒可讀區；右側約 46–96% 為九尾與動作區。
- 背景生成時就要為命牒留空，不得用普通人物圖再硬蓋一張紙。
- 手機：需獨立直式構圖或安全的上下分區；不可把桌機橫圖硬裁。
- 命牒標題固定；內文可捲；捲軸／底部漸層需讓玩家看得出還有內容；逐字寫入自動跟隨。

### S-OPERATE｜操作幕
- 主要 hotspot／道具放畫面中間安全範圍，避開對話框。
- hotspot 必須使用原始圖片 normalized 座標／SVG viewBox，不用螢幕座標硬寫。

## 五、手機固定安全規則

- 上方 0–12%：狐耳／頭飾禁裁區。
- 中上 16–60%：臉、上半身、主要動作黃金區。
- 下方 62–100%：對話／選項／提示預留區。
- 重要手勢若在下方，UI 必須移位或減高，不可以用 UI 蓋手。
- 每張圖要有獨立 `mobileFocus`；不做全站共同位移。
- 只有構圖本身適合時才允許同一張圖同時給桌機與手機。

## 六、狀態標記

- `🟢 保留`：故事和圖片語意一致，主要只需實機確認焦點。
- `🟡 校正`：圖可保留，但 focus、手機、文字、角色一致性或裁切要修。
- `🟠 換現有圖`：目前圖不夠對題，先從 V58 active/library 換。
- `🔴 專用新圖`：故事動作高度具體，若素材庫沒有就生成新圖。
- `🔧 程式必修`：圖片不一定要換，但互動／流程／命牒／hotspot 必須改。
- `⬜ 未鎖`：尚未完整驗收。
- `🔒 LOCKED`：使用者核准後才能使用；後續其他頁修改不得連帶改動。

## 七、四卷動態試煉頁特別規則

緣、業、命、禁各有一個動態試煉頁，不完全存在於各卷靜態 `scenes` 陣列中；它們由 branch trial / variantArt / reactionArt 組成。

因此正式鎖頁時必須額外檢查：

- 主試煉背景。
- 每個選項的 variantArt。
- 每個反應的 reactionArt。
- 對應手機圖。
- hotspot / 點觸區域。

## 八、卷別節奏不可互換

### 緣之卷
靠近、曖昧、臉、唇、手、紅線最多；性感與雙向距離是主體。

### 業之卷
棋盤、成果、署名、卷宗、交換、證據是主體；九尾是冷靜操盤者，不可整卷只有肖像。

### 命之卷
水、影、鏡、不同步、身體訊號是主體；恐怖來自「哪裡不對」，不是跳嚇。

### 禁之卷
狐面、禁線、試探、近身、威脅、控制同時存在；性感必須和危險一起出現。

### 真命卷
前四卷規則開始失效；九尾第一次真正失控；UI 退後、畫面更壓迫；最後才重新出現完整選擇與總命牒。

## 十、鎖頁流程

每幕依序：

`故事定稿 → 圖片需求定稿 → 現圖比對 → 桌機安全區 → 手機安全區 → 互動 → 動態分支圖 → 實機驗收 → 使用者確認 → 🔒 LOCKED`

任何一項沒有完成，都不能因為「圖片看起來漂亮」就鎖頁。

## 十一、本階段不做的事

- 不修改 `main`。
- 不一次重做整站。
- 不先整理全站 CSS。
- 不刪除既有圖片或舊規格文件。
- 不在圖片尚未鎖定前大改程式。

V1 完成後，先從緣之卷逐幕實機確認；緣卷鎖完再精準修改 V58 該卷，接著依序業 → 命 → 禁 → 真命。
