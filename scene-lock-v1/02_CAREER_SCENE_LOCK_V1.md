# 櫻隱 V58｜業之卷 12 幕完整逐幕鎖頁表 V1

> 卷別定位：成果、署名、交換、選擇權。
>
> 情緒曲線：**看盤 → 辨認成果 → 發現借名 → 壓力加碼 → 看見自己其實是棋手 → 留下條件 → 署名收卷。**

## 01｜棋室開局 `career.threshold`

**故事內容**：九尾不算玩家有多努力，而是看棋盤上誰能帶走成果。她要玩家先說，最近最想從工作裡拿回什麼。

**目前圖片**：桌機 `CAREER_chess_command_v44.webp`；手機 `career_017.webp`。

**需要畫面**：九尾坐在真實棋盤前，黑棋像工時，白棋刻著別人的名字。不能只是持扇肖像。

**文字安全區**：桌機 S-R 或 S-L 依棋盤位置；手機人物中上、棋盤需保留中下方可見區。

**注意事項**：棋盤與九尾要同時看得懂；不能因人物太大把棋局吃掉。

**第一輪決策**：🟢 保留候選。
**鎖定**：⬜

## 02｜成果署名 `career.name`

**故事內容**：九尾把完成、解危、救場三張成果牌翻面，要玩家看最重要的一次成果最後先被說成誰的名字。

**目前圖片**：桌機 `CAREER_02_table_cards_choice_v39.webp`；手機 `CAREER_02_table_cards_choice_mobile.webp`。

**需要畫面**：桌上有成果牌、姓名標記、九尾翻牌或指牌；不是單純站立。

**文字安全區**：S-EVIDENCE，文字放卡牌相反側。

**注意事項**：卡牌／姓名標記要能被視覺辨識；文字不可蓋牌面。

**第一輪決策**：🟢 保留。
**鎖定**：⬜

## 03｜無名籤牌 `career.black-piece`

**故事內容**：九尾在藍燈檔案室抽出一塊沒有名字的籤牌，問玩家如果明天不在，什麼能跟著自己走。

**目前圖片**：桌機 `career_002.webp`；手機目前借用 `CAREER_01_fan_command_mobile.webp`。

**需要畫面**：無名籤牌、檔案室、黑棋或成果載體；玩家伸手可接到，九尾的手勢清楚。

**文字安全區**：S-L / S-R，籤牌與手必須在非文字側。

**注意事項**：手機圖目前不是明確配對素材，要驗證是否真的有籤牌／接牌故事。

**第一輪決策**：🟡 桌機可留，手機需重驗。
**鎖定**：⬜

## 04｜加碼交換 `career.exchange`

**故事內容**：九尾把一疊任務推向玩家，每多接一張，玩家的黑棋就淡一分。她點破「只有你能做」若沒有資源、時間、職稱或報酬，只是更漂亮的佔用。

**目前圖片**：桌機 `career_003.webp`；手機 `career_016.webp`。

**需要畫面**：任務紙、扇骨壓紙、黑棋、交換感。九尾要像在談條件，不是單純漂亮坐姿。

**文字安全區**：S-EVIDENCE。

**注意事項**：一定要有「任務被推向玩家」或「交換條件」的具體視覺元素。

**第一輪決策**：🟡 語意重驗。
**鎖定**：⬜

## 05｜成果借名 `career.borrowed`

**故事內容**：玩家做過的每件事都變成一枚棋，卻在落地瞬間刻上別人的姓。九尾指出，若只有玩家被抹掉，那不是謙虛，而是系統已學會怎麼使用玩家。

**目前圖片**：V58 實際故事使用 `career_name_swap` 對應圖；舊鎖頁表列 `career_borrowed_evidence.webp`。

**需要畫面**：這是業卷最重要的證據幕：玩家成果／資料清楚存在，但另一人的姓名牌、印章或署名壓在上面；九尾用兩指把證據推向玩家，表情冷靜、略帶「現在看懂了嗎？」。

**文字安全區**：S-EVIDENCE。證據必須保留至少 25–35% 畫面空間。

**注意事項**：
- 不可只靠台詞說「成果被拿走」。
- 名字、印章、成果三者至少要有兩個能一眼看懂。
- 九尾可坐在策略桌另一側，胸、腰、手、證據完整。

**第一輪決策**：🔴 關鍵場景，現圖若不完整就專用新圖。
**鎖定**：⬜

## 06｜雨局壓力 `career.pressure`

**故事內容**：屋頂裂開，雨落棋盤。玩家每說一次「最近太忙」，就有一格盤面被沖掉。九尾要玩家選一個最能留下選擇權的動作。

**目前圖片**：桌機 `CAREER_03_rain_standing_pressure_v39.webp`；手機 `CAREER_03_rain_standing_pressure_mobile.webp`。

**需要畫面**：雨、棋盤、壓迫、九尾；最好能看到盤面被雨侵蝕或光線變暗。

**文字安全區**：S-L / S-R，棋盤不可被大段文字遮住。

**注意事項**：不能只是一張雨中站姿照；棋局壓力感要在畫面裡。

**第一輪決策**：🟢 圖保留候選，需實機驗棋盤可見度。
**鎖定**：⬜

## 07｜棋手反轉 `career.turn`

**故事內容**：九尾抬起整張棋盤，盤底不是桌面，而是一雙雙等玩家替它完成最後一步的手。她指出玩家不是棋子，而是讓所有棋局繼續運作的那隻手。

**目前圖片**：桌機 `career_new_01.webp`；手機 `career_015.webp`。

**需要畫面**：抬起棋盤／盤底多雙手／唯一黑棋放進玩家掌心。這是一幕「身份反轉」。

**文字安全區**：S-EVIDENCE 或中構圖短句；盤底異象不能被遮。

**注意事項**：若現圖只是一張九尾持棋肖像，故事力不足。

**第一輪決策**：🟠 高度敘事場景，現圖需嚴格重驗。
**鎖定**：⬜

**注意事項**：這幕要有「選擇在減少」的視覺感，不是泛用工作氛圍圖。

**第一輪決策**：🟡 保留候選，驗異象是否足夠清楚。

**互動**：落子／選一格，hotspot 必須綁棋盤原始座標或 SVG，不可依螢幕像素硬寫。

**注意事項**：四個 trial variantArt / reactionArt 都要分別驗，不可只鎖主圖。

**第一輪決策**：🔴 互動與圖片雙重必修。
