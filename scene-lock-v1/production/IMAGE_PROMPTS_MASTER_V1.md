# 櫻隱｜生圖總表 V1

> 用途：整理目前《櫻隱》網站中已確認需要新生成圖片、或高優先待生成圖片的完整提示詞與控管欄位。
> 建議策略：先暫停最後一輪大量生圖，先整理成總表，再同步進行網站其他調整；等網站現有圖片、命牒、hotspot、手機裁切等能修的都先修完，再依此檔逐張生成。

---

## 一、建議結論

### 建議做法：**先不要一次把所有圖都生成完**
原因如下：
1. 目前已經確認有一部分問題可以靠 **現有素材替換** 解決，不需要浪費生成次數。
2. 網站還有幾個比生圖更急的項目，例如：
   - 命牒卷軸與逐字捲動
   - 手機 focus / 構圖裁切
   - hotspot 點位
   - 同圖重複使用造成的劇情錯配
3. 若現在一次生成太多，後面網站畫面一改，文字安全區或角色站位可能又要重來。
4. 先整理成「生圖總表」，之後你逐張處理會更穩，也比較不會漏。

### 最佳順序
1. **先整理生圖總表**（本檔）
2. **先修網站其他已知問題**
3. **再按優先順序逐張生圖**
4. **每生完一張，再回網站驗證桌機／手機與文字安全區**

## 八、我的建議

### 我認為最好的做法是：
**對，不要現在一次生成到底。**

而是：
- 我先把「要生圖的相關資料」整理成這種總表檔給你。
- 你之後逐一處理圖片。
- 我這邊繼續把網站其他能先修的地方先整理、先調整。

這樣最穩，理由是：
1. 不會浪費生圖次數。
2. 不會先生成，後面又因網站構圖改動重來。
3. 圖與網站可以同步收斂。
4. 整體完成度會比「先狂生圖」更高。
