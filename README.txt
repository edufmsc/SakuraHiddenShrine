櫻隱命館 V58

【這一包是什麼】
這是目前可直接使用的正式網站版本。正式交付包只保留最新版程式、部署必要檔案、音效與圖片素材；不附舊版本程式、舊 README、測試截圖、QA 工具或備份檔。

【使用方式】
1. 將 ZIP 完整解壓縮。
2. 若要放上 GitHub Pages，請把解壓後內容放在儲存庫根目錄，保留 .github、.nojekyll 與 assets 資料夾結構。
3. 首頁入口為 index.html。
4. 不要任意改動 assets/images/active 的檔名或路徑，程式會依場景載入指定圖片。

【V58 鎖定呈現規則】
- 故事主畫面維持滿版插畫，不讓文字遮住九尾的臉、胸線、手勢或主要劇情道具。
- 圖片必須對應當幕故事意義；一般主場景避免重複，同一張鏡像圖僅在第五卷作為刻意伏筆回收。
- 緣／業／命／禁四卷命牒：先以九尾與該卷場景滿版鋪底，再於左側覆蓋大型米白命牒；不是左右兩個獨立版面。
- 命牒自動逐字慢寫；關鍵段落會停筆並以「……」思考後繼續。完整文字超出時會自動壓縮排版或在命牒內安全捲動，不直接裁字。
- 一般故事不自動跳幕，玩家自己決定何時繼續。
- 緣卷保留臉頰／唇前等畫面互動，使用可察覺但不突兀的微光提示。
- 第五卷不再增加中途問卷，重點是四卷伏筆回流、九尾失控、坦白、第五問與最後三個真正選擇。
- 第五卷可重看。
- 真正結局停留在黎明畫面；「櫻隱・終」置中大型顯示，之後於中央偏下出現「回到命館｜重新起盤」，不會自動離開。

【圖片資料夾】
assets/images/active/
目前程式正式使用或正式程式仍有引用的圖片，依首頁、緣、業、命、禁、第五卷、終幕、共用素材與道具分類。

assets/images/library/
保留但目前不作為正式主流程使用的素材，依用途分類。與 active 完全相同的重複檔已移除，避免多占空間。

完整檔名請看 IMAGE_INDEX.txt。
